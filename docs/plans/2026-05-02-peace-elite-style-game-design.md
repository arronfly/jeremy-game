# 歼灭团竞2 - 设计文档

## 项目概述
- **游戏名**: 歼灭团竞2 (Peace Elite Style)
- **类型**: 写实风格2D俯视角团队竞技游戏
- **引擎**: Phaser.js 3.x
- **目标用户**: Jeremy (13+) 和朋友

## 地图设计 - "假车库"风格

### 布局
```
┌────────────────────────────────────────────────────────────┐
│  [车库A]        掩体A         掩体B         [车库B]           │
│  红队出生点                                              │
│         ████████                          ████████         │
│                                                           │
│    围墙            中央掩体群              围墙            │
│                                                           │
│         窗户                    窗户                       │
│    ██████████              ██████████                     │
│                                                           │
│  [仓库]        掩体C         掩体D         [仓库]           │
│                    蓝队出生点                             │
└────────────────────────────────────────────────────────────┘
```

### 地图元素
- **车库建筑**: 可进入，有屋顶遮蔽，窗户可穿透射击
- **围墙**: 完整掩体，无法穿透
- **掩体**: 半高掩体，可躲避但不能永久藏身
- **窗户**: 半穿透，可以射击但会暴露位置

### 尺寸
- 地图尺寸: 1600 x 1200 pixels
- 车位格子: 64x64 pixels

## 角色系统

### 角色外观（写实风格）
- 俯视角可见：头部（圆形）、躯干（椭圆形）、四肢（线条）
- 有阴影（角色脚下椭圆形黑色阴影）
- 有方向光效（朝上方向有高光）
- 尺寸: 48x48 pixels

### 动画帧
| 动画 | 帧数 | 用途 |
|------|------|------|
| idle | 4 | 待机站立 |
| walk | 6 | 行走 |
| run | 6 | 奔跑 |
| shoot | 4 | 射击 |
| reload | 8 | 换弹 |
| hurt | 3 | 受伤 |
| death | 5 | 倒地 |
| throw | 5 | 投掷 |

### 属性
- 移动速度: 150 pixels/sec（原版250）
- 生命值: 100
- 半径: 20 pixels

## 武器系统

| 武器 | 伤害 | 射速 | 弹夹 | 备弹 | 特点 |
|------|------|------|------|------|------|
| 突击步枪 | 25 | 400ms | 30 | 120 | 中距离，连发 |
| 狙击枪 | 80 | 1500ms | 5 | 20 | 远距离，单发 |
| 冲锋枪 | 18 | 200ms | 35 | 140 | 近距离，高射速 |
| 散弹枪 | 15x8 | 800ms | 8 | 32 | 短距离，8颗弹丸 |

### 武器切换
- 数字键 1-4 切换武器
- R 键换弹

## 投掷物系统

| 物品 | 冷却 | 效果 |
|------|------|------|
| 烟雾弹 | 3s | 形成烟雾区域，持续5秒，遮挡视野 |
| 闪光弹 | 3s | 敌人致盲2秒，范围5米 |
| 手雷 | 3s | 范围伤害50点，持续伤害 |

### 投掷操作
- 鼠标滚轮或 G 键切换投掷物
- 右键投掷（蓄力可投更远）

## 药品系统

| 药品 | 冷却 | 效果 |
|------|------|------|
| 急救包 | 10s | 恢复50点生命，播放动画3秒 |
| 绷带 | 5s | 恢复10点生命，播放动画1秒 |
| 能量饮料 | 8s | 持续恢复25点生命 + 移动速度+20%，持续10秒 |

### 药品操作
- 7键使用急救包
- 8键使用绷带
- 9键使用能量饮料

## 比赛规则

### 回合制
- 每回合开始，两队全员重生
- 一方全灭，另一方存活者得分
- 先得4分者获胜（7局制）

### 计分
- 获胜队伍+1分
- 平局（同时全灭）两队不得分

### 决胜局（3:3）
- 全员出击，最后站着的队伍获胜

### 游戏流程
```
开始界面 → 选择队伍 → 等待匹配 → 游戏加载
    ↓
第1回合 ←→ 第2回合 ←→ ... ←→ 第7回合
    ↓                    ↓
 红队胜利            蓝队胜利
    ↓                    ↓
 结算界面（显示比分、战绩）
```

## 技术架构

### 依赖
- Phaser 3.60+
- 无其他外部依赖

### 场景结构
```
BootScene      → 加载资源
MenuScene      → 开始界面
LoadScene      → 加载游戏资源
GameScene      → 主游戏
EndScene       → 结算界面
```

### 网络（可选）
- 暂不支持多人在线
- 未来可添加Phaser Photon或WebSocket

## 验收标准
1. ✅ 地图呈现"假车库"风格，有车库、围墙、掩体
2. ✅ 角色有立体感：头、躯干、四肢、阴影
3. ✅ 动画流畅：待机、行走、射击、换弹、倒地
4. ✅ 武器系统：4种武器各具特色
5. ✅ 投掷物：烟雾、闪光、手雷
6. ✅ 药品：急救包、绷带、能量饮料
7. ✅ 移动速度适中，不会太快
8. ✅ 7局4胜制，3:3时决胜局
